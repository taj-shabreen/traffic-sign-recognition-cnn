# Traffic Sign Recognition using CNN

## Overview

This project develops a Deep Learning based Traffic Sign Recognition System using Convolutional Neural Networks (CNNs).

The system automatically identifies and classifies traffic signs from images, supporting intelligent transportation systems and autonomous driving applications.

## Features

* Traffic sign image preprocessing
* CNN-based classification
* Multi-class image recognition
* Deep learning model training
* Performance evaluation
* Prediction visualization

## Tech Stack

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Workflow

1. Load traffic sign dataset
2. Preprocess images
3. Build CNN architecture
4. Train model
5. Evaluate performance
6. Predict traffic sign classes
7. Visualize results
